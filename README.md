## Overview

**PixelSense-Lite** is an end-to-end audio data QA, drift detection, and `.tflite` quantization pipeline for environmental audio classification (`coughing`, `snoring`, `siren`, `crying_baby` vs. `background_noise`), built on a 320-clip subset of [ESC-50](https://github.com/karolpiczak/ESC-50).

1. **Ingestion & Signal QA ([`ingest_qa.py`](./ingest_qa.py))**: Screens incoming WAV recordings for clipping, DC offset bias, dead air, and human vocal bleed in background noise classes.
2. **Consensus & Drift Audit ([`consensus_drift.py`](./consensus_drift.py))**: Runs group-isolated (`src_file`) out-of-fold teacher consensus to identify noisy labels and computes Population Stability Index (PSI) spectral drift across clean and degraded evaluation slices.
3. **Training & Quantization ([`train_quantize.py`](./train_quantize.py))**: Trains a compact 2D CNN and exports `fp32`, `fp16`, and full-integer `int8` `.tflite` flatbuffers.
4. **Release Gate ([`release_gate.py`](./release_gate.py))**: Verifies subgraph INT8 operator compliance, model footprint, and multi-slice macro F1 before approving a release candidate.

## Release Gate Scorecard (`v1_baseline` vs. `v2_data_flywheel`)

- **`v1_baseline` (BLOCKED)**: Trained on clean Folds 1–4 clips (`w = 1.0`). Fails degraded evaluation slices (`pocket_occluded` and `appliance_noise_3db`).
- **`v2_data_flywheel` (SHIP / PASS)**: Triggered by Stage 2 spectral drift (`PSI > 0.25`); down-weights disputed training labels (`w = 0.35`) and augments Folds 1–4 with disjoint Butterworth low-pass filters (1,350 Hz, 2,100 Hz) and domestic interferer mixing (+2.0 dB, +5.5 dB SNR).

