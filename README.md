## 1. Architecture & Overview

**PixelSense-Lite** is a 5-stage data and `.tflite` release pipeline for always-on environmental audio classification (`coughing`, `snoring`, `siren`, `crying_baby` vs. domestic `background_noise`) on low-power DSP cores, built on a 320-clip subset of [ESC-50](https://github.com/karolpiczak/ESC-50):

```mermaid
flowchart LR
    A[Raw Audio Corpus] --> B{Stage 1: Signal & Speech Gate}
    B -- Clipping / DC Bias / Speech Band --> Q1[Quarantine CSV]
    B -- Clean Signal --> C{Stage 2: OOF Kappa & PSI Drift}
    C -- High-Confidence Disagreement --> Q2[Down-Weight Noisy Labels]
    C -- PSI > 0.25 --> D[Stage 3: v2 Domain Augmentation]
    D --> E[Int8 LiteRT Compiler]
    E --> F{Stage 4: Subgraph & Slice Gate}
    F -- Flash <= 45KB & 0% Float Fallback & Slice Pass --> G([PASS RELEASE GATE])
    F -- Regression Detected --> H([BLOCK RELEASE])
```
